# Input data specification

**No data files are distributed with this repository** (except `hub_genes_9.csv`,
`methods.csv`, `ML.R` and `gene set/`). All other inputs must be downloaded from
public databases or prepared by the user.

Every file listed below must be placed in this `data/` folder.

---

## A. Included in this repository

| File | Format | Description |
|------|--------|-------------|
| `hub_genes_9.csv` | CSV, header `Gene` | The nine hub HICGs, one gene symbol per row. Obtained by intersecting the COPD-associated DEGs with the HICG set and then retaining the genes selected by the 107-model machine-learning pipeline in `Fig3.R`. |
| `methods.csv` | CSV, header `Model` | The 107 machine-learning algorithm combinations used in Figure 3. |
| `ML.R` | R script | Machine-learning function library. |
| `gene set/<name>.txt` | tab-delimited, header `Genes` | HICG gene set. |

---

## B. Download from public databases

### B1. Bulk transcriptomic datasets

| Folder | Accession | Role |
|--------|-----------|------|
| `raw/GSE76925/` | GEO GSE76925 | discovery cohort (combined with GSE20257) |
| `raw/GSE20257/` | GEO GSE20257 | discovery cohort (combined with GSE76925) |
| `raw/GSE106986/` | GEO GSE106986 | independent validation cohort |
| `raw/GSE38974/` | GEO GSE38974 | independent validation cohort |
| `raw/GSE8545/` | GEO GSE8545 | independent validation cohort |

Each folder must contain:

```
raw/GSE76925/
├── GSE76925_series_matrix.txt      expression matrix
├── GPLxxxxx.txt                    platform annotation
└── sample_info.xlsx                prepared by the user (see section C)
```

The platform file must contain a gene symbol column; `Fig2.R` reads column 11 of
the platform file by default (`gene_col_index <- 11`) - adjust this value if your
platform file uses a different column.

### B2. Single-cell dataset

```
raw_10x/
├── Control_1/     barcodes.tsv.gz  features.tsv.gz  matrix.mtx.gz
├── Control_2/
├── ...
└── Disease_5/
```

Source: GEO **GSE173896** (5 COPD patients, 3 healthy controls).
Folder names must start with `Control` or `Disease`; the script prefixes every
cell barcode accordingly, which is how the groups are defined downstream.

### B3. Annotation and pathway resources

| File | Source | Description |
|------|--------|-------------|
| `c2.cp.kegg.symbols.gmt` | MSigDB (C2:CP, symbol format) | KEGG gene sets used in `Fig5.R`. Registration required; not redistributed here. |
| `refer.txt` | CIBERSORT | LM22 signature matrix: genes in rows, 22 immune cell types in columns, tab-delimited. |
| `genes.txt`, `probesets.txt` | MCPcounter R package | MCP-counter annotation. Export from the package or download the annotation files from the MCP-counter resource. |

## C. Prepare from the downloaded data

### C1. `sample_info.xlsx` (one per bulk dataset) - created manually by the user

This file is **not generated by any script**; it must be prepared manually. It contains
two columns with a header row (any column names are accepted):

| Accession | Source name |
|-----------|-------------|
| GSM265019 | con |
| GSM265020 | tre |

- Column 1: sample accession as it appears in the GEO series matrix (e.g. `GSM265019`).
- Column 2: group label - `con` for control, `tre` for disease.
- The script normalises the labels automatically, so `Control`, `control`, `Disease`,
  `treat`, `treatment` and `tra` are also accepted and converted to `con`/`tre`.
- Place one file in each `data/raw/<GSE>/` folder, named `sample_info.xlsx`.

### C2. Machine-learning inputs for `Fig3.R`

| File | Format | Description |
|------|--------|-------------|
| `Training_expr.txt` | tab-delimited; first, unnamed column = gene symbols, header row = sample IDs | batch-corrected expression matrix of the discovery cohort produced by `Fig2.R`; the 13 intersection genes are in rows and the 286 samples in columns |
| `Training_class.txt` | tab-delimited; columns `sample` and `outcome` | one row per sample; `outcome` = 0 (control) / 1 (COPD); row names must match the columns of `Training_expr.txt` |
| `Testing_expr.txt` | same layout as `Training_expr.txt` | expression matrix of the three validation cohorts (13 genes x 87 samples) |
| `Testing_class.txt` | tab-delimited; columns `Sample`, `Cohort` and `outcome` | one row per sample; `Cohort` gives the dataset of origin (GSE106986 = 19, GSE38974 = 32, GSE8545 = 36) and `outcome` = 0 / 1 |
| `test_GSE8545.csv` | CSV, samples in rows, hub genes in columns | first column = sample ID ending with `_con` or `_tre`; generated automatically by `Fig2.R`, no manual preparation needed |
| `test_GSE106986.csv` | same | independent validation cohort |
| `test_GSE38974.csv` | same | independent validation cohort |

### C3. `merged_after_batch_removal.csv` (for `Fig3.R`-`Fig8.R` and `Fig10.py`)

Batch-corrected expression matrix of the discovery cohort: the first column
(`geneSymbol`) holds gene symbols and each remaining column is one sample, whose name
ends with `_con` (control) or `_tre` (disease). **This file is produced automatically
by `Fig2.R` in the repository root** (not in `data/`); `Fig3.R`-`Fig8.R` and
`Fig10.py` read it from there.

### C4. Other files

| File | Format | Description |
|------|--------|-------------|
| `Inflammatory Cytokines gene.txt` | plain text, one gene symbol per line | 24 inflammatory cytokine genes |
| `clinical.xlsx` | first column = sample ID, remaining columns = clinical variables | Gender, Age, Pack-years, etc. Use de-identified data only. |

## D. Not distributed (and why)

| File or folder | Reason |
|----------------|--------|
| `raw/`, `raw_10x/` | large raw data; obtainable from GEO under the accessions above |
| `merged_after_batch_removal.csv` | derived matrix; regenerated by `Fig2.R` from the GEO data |
| `c2.cp.kegg.symbols.gmt` | MSigDB licence requires registration |
| `clinical.xlsx` | patient privacy; de-identified data may be requested from the corresponding author |
| DrugReflector source and checkpoints | third-party package, install separately |

---

## E. Naming conventions expected by the scripts

| Convention | Used by |
|------------|---------|
| sample names end with `_con` / `_tre` | all bulk expression matrices, including `merged_after_batch_removal.csv` |
| cell barcodes prefixed with `Control.` / `Disease.` | single-cell data (Fig9) |
| first column header `Gene` | `hub_genes_9.csv` and gene set files |
| first column header `Model` | `methods.csv` |
